The Morning Ledger

A daily market brief that assembles itself, degrades honestly when its sources are unreachable, and keeps a scored record of every call it makes. The interesting problems were never the data.

The failure that had no error message

The first version ran on a 9am cron. It worked, and the output was quietly worse every single day. Unattended runs could not reach the authenticated data sources, so each one silently fell back to a thinner substitute. The brief still published. It still looked complete. Nothing in it said otherwise.

The fix was not better error handling — it was changing when the job runs, so it happens while I am present and the sources connect. That one diagnosis shaped everything else in the system.

It grades its own calls

Any prediction specific enough to be checkable gets logged with a horizon date and the reasoning behind it, written before the outcome is known. When the horizon passes, a later run scores it and writes down which mechanism was misjudged. A system that only ever forecasts forward has no way to be wrong.

A sample grade, unedited

Half right. Direction was right, magnitude was badly wrong: predicted −1% to −2%, actual −0.05% — a 20–40× overestimate. Cause: sized the print as if it landed into an unchanged backdrop, but dovish comments 24h earlier had already moved the odds. The two events largely cancelled.

Lesson: size the delta versus what is already priced, not the absolute surprise.
